# Java Contact Manager

This project is a console-based contact management application developed in Java.

The application allows users to create, update, delete, and search contacts. It follows a layered architecture and separates responsibilities between application logic, service layer, persistence, and validation.

**Features**

CRUD operations for contacts

File-based data persistence

Input validation

Custom exception handling

Search functionality

Tag support for contacts

**Technologies**

Java 

File I/O

Git
